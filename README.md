# CSCI4221 Project 1: Student Task Tracker

## Project Overview

Student Task Tracker is a proposed web application that helps college students organize coursework. Students will be able to manage assignments, track due dates, and identify work that still needs to be completed.

Project 1 focuses on setting up GitHub and the development environment, defining the product vision, assigning responsibilities, and documenting the group's planning. Application development will follow in later project stages.

## Product Vision Statement

For college students who need a simple way to manage coursework, Student Task Tracker is a web application that organizes assignments, due dates, and completion status in one place. Unlike a paper to-do list, it allows students to update assignments, filter tasks by course or completion status, and view upcoming deadlines. Our goal is to help students stay organized and plan their work.

## Proposed Features

- Add assignments with a title, course, and due date.
- Edit or delete existing assignments.
- Mark assignments as complete.
- View assignments in order of their due dates.
- Filter assignments by course or completion status.
- Save assignment information locally in the browser.
